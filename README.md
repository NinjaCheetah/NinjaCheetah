### hey there!
**I'm Campbell/NinjaCheetah.** I'm a 19 (at the time of writing) year old programmer from the US. I've tried a little bit of everything, from a bit of Visual Basic to C#, C, Python, Swift, Rust, HTML/CSS/JS, Batch Scripting, and some Bash Scripting. I've currently settled in on Swift and Kotlin as my main languages, since I'm doing a lot of mobile app development.

I'm currently studying CompSci at the Rochester Institute of Technology. Since getting there, I've been working on a fancy native iOS dining app for myself and other students over at [NinjaCheetah/TigerDine](https://github.com/NinjaCheetah/TigerDine) which is far better than any of our official school apps, and I also [ported it to Android](https://github.com/NinjaCheetah/TigerDine-for-Android)!. (It even got noticed and okayed by RIT themselves!)

One of my other main focuses is developing for the Wii, though indirectly. C didn't stick for me, so instead of writing Homebrew for the Wii, I've taken to writing PC software to help with others' Wii modding antics. Much of the existing software is really aging at this point, and is designed for Windows-only, so I've taken to writing fresh software that's OS-independent (and then I get to benefit too as a Linux user!). My main project is [libWiiPy](https://github.com/NinjaCheetah/libWiiPy), a Python library desgined to eventually replace libWiiSharp, so that new Wii programs can be made in Python and therefore be entirely portable. I've started towards this goal with my other primary projects, [WiiPy](https://github.com/NinjaCheetah/WiiPy) and [NUSGet](https://github.com/NinjaCheetah/NUSGet). I'm also working on learning Rust for real, and I'm doing so by writing a Rust port of libWiiPy/WiiPy called [rustii](https://github.com/NinjaCheetah/rustii), which is pretty much ready to go at this point.
